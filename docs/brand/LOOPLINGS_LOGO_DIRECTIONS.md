# Looplings Logo Directions

This note captures the first mascot-led logo directions for Looplings.

Preview sheet:

- `public/brand/looplings-logo-variations.html`

## Source Character

The first pass uses the existing Prime L01 atlas as the mascot source:

- `public/pets/prime-test/state-atlas.png`
- cell size: `192x208`
- first frame: idle Prime, used for logo exploration

## Strongest Directions

### 1. Peek Wordmark

Prime's head rises from behind or below the word `looplings`.

This feels like the most approachable direction. It communicates the virtual
pet idea immediately and gives the brand a memorable mascot moment without
making the wordmark hard to read.

Best use cases:

- landing hero
- hackathon submission logo
- social banner
- product splash screen

### 2. Signal O

Prime's antenna loop replaces one of the `o` letters in `looplings`.

This is the strongest pure logo idea because it turns the creature detail into
a repeatable brand symbol. The halo can become a standalone icon, favicon, app
mark, loading indicator, or in-world device signal.

Best use cases:

- primary wordmark
- favicon/app icon
- merch
- tiny UI surfaces

### 3. Antenna I

Prime's antenna stem and halo become the `i` in `looplings`.

This is clever, but it needs careful spacing so the word remains readable. It
may work best as a secondary lockup rather than the default logo.

Best use cases:

- stickers
- animated intro
- playful social graphics

### 4. Room-Sign Lockup

Prime appears beside the wordmark as if the logo is signage inside the 3D room.

This fits the current Prime-room MVP because the brand can exist diegetically:
on the Steam Deck screen, wall signage, printed receipts, boot screens, and
status cards.

Best use cases:

- in-scene signage
- demo video title card
- receipt printer header
- Prime profile page

## Recommendation

Use the `signal O` concept as the long-term brand direction, with the `peek
wordmark` as the friendly launch/demo treatment.

The final system can be:

- primary wordmark: `looplings` with antenna-loop `o`
- mascot lockup: Prime peeking over the wordmark
- app icon: antenna halo plus simplified Prime head
- in-world mark: compact `L01` / halo badge for Prime-specific surfaces
